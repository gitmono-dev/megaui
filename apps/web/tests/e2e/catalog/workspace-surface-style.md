# 全站文档样式基线

- Spec：`apps/web/tests/e2e/workspace-surface-style.spec.ts`
- 数据：`helpers/surface-fixture.ts` 固定 BFF 数据，真实登录会话、真实 Compose 前端；不修改用户页面。
- 基准：运行时读取文档详情页标题，逐页比较字体、字号、字重、行高、字距和文字颜色。
- 范围：Home、Docs／图谱／详情、Issue／详情、Inbox、Agent、Session、Code／路径、Tag、CL／五个详情标签、频道创建／会话／DM、七个设置分区。
- 主题：亮色与深色画布、表单、卡片和按钮；紧凑密度切换后的字号、键盘焦点和选中态。
- 响应式：320、768、1024、1440、1920px 下检查页面铺满工作区，并核对横向溢出。
- 公共页面：中英文入口、登录、注册、找回密码、重置密码共用背景、面板与主按钮样式。
- 截图：测试输出目录包含主题和响应式截图。

业务数据、权限、编辑、发布、代码高亮和图谱的功能仍由相应页面 spec 验证；此 spec 只约束共用的视觉与布局行为。
