## Live-tier runbook

```bash
docker compose -p mega2-it -f ../mega2/docker-compose.test.yml \
  --profile app --profile web up -d --build --wait
curl -sf http://127.0.0.1:17001/api/health
curl -sf http://127.0.0.1:17002/health
docker compose -p mega2-it -f ../mega2/docker-compose.test.yml images website-next megaui-collab
# record digests in docs/implementation/live-e2e-notes.md

export E2E_BASE_URL=http://127.0.0.1:17001 E2E_SKIP_WEBSERVER=1
export DATABASE_URL=postgresql://mega2:replace-with-db-password@127.0.0.1:15432/website
export BETTER_AUTH_URL=http://127.0.0.1:17001 APP_BASE_URL=http://127.0.0.1:17001
export BETTER_AUTH_TRUSTED_ORIGINS=http://localhost:17001,http://127.0.0.1:17001
export MEGA2_PUBLIC_BASE_URL=http://127.0.0.1:19180
export NEXT_PUBLIC_MEGA_COLLAB_PUBLIC_URL=ws://127.0.0.1:17002
# plus S3_* matching compose when running upload.spec.ts
#
# Secret-bearing exports (BETTER_AUTH_SECRET, MEGA_COLLAB_INTERNAL_TOKEN) are
# intentionally not written here: they must match the values in
# ../mega2/docker-compose.test.yml, and recording them literally would
# violate ER-11 residue discipline. Export them from the compose env (or a local
# .env kept out of VCS) before running live-tier specs.

pnpm exec playwright test apps/web/tests/e2e/<live-specs>
```

See `docs/implementation/live-e2e-notes.md` for digests and re-pin notes.

- 飞书登录验证码页错误提示：[feishu-login-verify-errors](catalog/feishu-login-verify-errors.md)（错码与格式非法显示「验证码无效或已过期」并停留在验证码步骤，预置同邮箱本地用户触发的 409 显示账号冲突，注入会话签发故障触发的 503 提示重新获取验证码；专用配置 `playwright.feishu-login.config.ts`）

- 飞书登录验证码页重新发送与更换邮箱：[feishu-login-resend](catalog/feishu-login-resend.md)（实际等待 61 秒，不用假时钟：60 秒内重发不可用；重发后旧码无效、新码可登录、库中新行激活、Mock 收件箱收到第二条私聊；重发失败（注入的 503）时提示失败、保留验证码并重新倒计时；更换邮箱回到邮箱步骤，为命中与未命中的新邮箱请求后旧邮箱的验证码都无效；专用配置 `playwright.feishu-login.config.ts`）

- 飞书模式的登录入口：[feishu-login-entry](catalog/feishu-login-entry.md)（访客访问 `/[lang]/signin` 得到 307 到 `/[lang]/signin/feishu`、保留查询参数，受保护页面经 `/[lang]/signin` 最终到达飞书登录页，页面没有密码表单与注册链接；注册、找回密码与重置密码页面返回 404；专用配置 `playwright.feishu-login.config.ts`）
