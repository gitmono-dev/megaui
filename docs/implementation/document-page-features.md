# 文档页编辑功能

## 文档发布

文档默认是 Draft（草稿）。有编辑权限的用户在最新文档页点击 Publish（发布），编辑器先保存当前内容并等待尚未完成的自动保存，然后将状态改为 Published（已发布），同时生成“Published document”版本快照。状态与快照在同一数据库事务中提交，重复或并发发布不会重复生成快照。保存或发布失败会显示错误，保留正文并允许重试。

已发布文档可通过 Return to draft（撤回为草稿）恢复为草稿；再次发布生成新的快照。发布后仍可编辑和自动保存，当前文档继续显示已发布，发布时的快照保持不变；需要草稿状态时先撤回。发布状态不改变现有工作区可见性或分享权限。只读用户与历史快照页面不显示发布操作，服务端仍验证写权限。

状态接口为 `POST /api/mega/docs/:id/publish` 与 `POST /api/mega/docs/:id/unpublish`，返回更新后的文档；`meta` 的状态字段支持 `draft | published`，共用同一事务路径。旧持久化值 `adopted` 读取为 `published`，后续状态操作写入新值。文档响应的 `canEdit` 由服务端权限服务计算。未登录返回 401、没有写权限返回 403、文档不存在返回 404。

## 编辑与引用

所有新建块统一使用 12 位短 ID，字符集为 `A-Z`、`a-z`、`0-9`、`_`、`-`。生成器位于 `@megaui/core`，使用 `crypto.getRandomValues` 产生 72 位随机身份；普通块、代码块、分隔线、表格及其来源大纲、空文档与导入产生的块共用该生成器。复制结果为 `((zK7QQWAdv_12))`；聚焦链接、块引用与 embed 保留相同 ID。保存正文与引用解析接口仅接受该格式，拒绝旧 UUID 与其它长度，不提供旧 ID 兼容或迁移。

文档正文使用块级大纲。右键块圆点或正文可以复制块引用、嵌入宏、块链接与块 ID；「展开全部／折叠全部」只作用于当前块及其子块。「在侧栏打开」会显示该块及子块的可编辑视图与祖先路径，`Ctrl+Shift+O` 可在光标所在块执行同一操作。原始块右侧的数字表示当前用户可读取的引用次数，点击数字可查看来源。

侧栏与正文即时双向同步，共用正文的协作连接、自动保存队列和撤销／重做历史；不创建独立的子树副本或第二个保存请求。侧栏 Enter 会继续在当前子树中创建可见行，关闭侧栏不会丢失最后输入；发布也会等待侧栏最新内容保存。只读用户与历史快照继续使用只读视图，删除目标块后显示不可用状态。

正文与侧栏默认按约 55:45 分配可用区域。拖动分隔条可调整宽度；聚焦分隔条后按左右方向键调整，Shift 加速，Home／End 到达最小／最大宽度，双击恢复默认比例。同一页面关闭再打开侧栏保留调整比例；可用区域小于 760px 时改为上下排列，避免把两边编辑器挤得过窄。

「Copy block ID」与「Copy block ref」均复制 `((块 ID))`，富文本剪贴板同时携带源文档 ID。粘贴或输入完整语法会创建行内块引用，前后可继续输入普通文字；非编辑状态显示来源块正文，光标进入所在行时显示引用语法，点击引用可编辑 ID。语法末尾按右箭头返回正文继续编辑同一行。引用保存为结构化节点，编辑显示方式不会修改来源块。裸 ID 通过有权限的块索引解析；跨文档 ID 重复且没有匹配来源时保持未解析，不任意选择来源。

通过 `?block=` 链接或「聚焦块」进入子树编辑时，在聚焦块上按 Enter 会在其已有子块之前创建新子块，并将光标移到新行；已有子块保持原有顺序，折叠的聚焦块会展开。在子块内继续按 Enter 会创建同级行，仍留在当前聚焦子树内。编辑引用语法后按 Enter 也遵循相同规则，正文与侧栏均适用。按 Escape 返回完整文档，新增行保留在原块下。

引用节点持久化 `binding`：复制的完整来源及成功解析的引用为 `document`，仅裸 ID 搜索为 `search`；未指定时按明确文档来源处理。来源暂时不可读或已删除时，保存与重新打开不会改变其文档身份，也不会转而显示另一篇文档中相同 ID 的块。

`#标签` 的井号与文字显示为同一个浅灰蓝色链接（参照 2026-10-27 Roam 的 `#Anthropic`），删除时一并移除。旧文档中拆分保存的井号与标签会在编辑／阅读时兼容转换，保留前后文字及引用目标；转换标记确保再次打开不会多出或丢失井号。数字 `#42` 仍表示 Issue 引用。在标签或块引用之后按退格不会合并整行，只有光标真正位于块正文开头时才执行合并。

页面底部的 Backlinks 汇总当前用户可读取的、指向整篇文档及其各块的引用，包括页面链接、块引用和块嵌入；聚焦块时仍使用该文档范围。列表按来源类型与 ID 合并，同一来源只显示一个标题，多次引用以标题右上角的数字表示，单次不显示数字。同名但不同来源的条目保持独立，原始块旁的引用计数仍只统计该块。

输入 `/` 可选择 TODO、页面引用、块引用、标签、2×2 表格和图片。文档使用纸张色背景，页面引用以蓝色显示标题、以灰蓝色显示双方括号。快捷菜单与块右键菜单共用工作区的字体密度、行高、圆角、边框、阴影及选中背景，菜单宽度为 14rem，快捷提示沿右侧对齐。新表格按 Roam 的层级方式保存：表格下方显示同一组普通 Outliner 块，每行是一个子块，后续列沿该行的第一个子块逐级嵌套。表格是这些块的实时视图；在纯文本单元格或下方大纲修改文字会同步到另一处，保存和重新打开后仍保持关联。带格式的单元格须在下方大纲编辑，以免丢失链接或格式。聚焦单元格可添加／删除行列或删除整个表格，这些操作直接修改对应的 Outliner 块；Tab 在最后一个单元格会新建一行。旧文档中的独立 Lexical 表格继续保留原来的显示和操作方式。外部 HTTP(S) 地址与电子邮件地址会自动转为链接，保存后在阅读视图中仍可点击。

图片可通过 `/image` 输入 HTTP(S) 图片网址、上传 PNG／JPEG／GIF／WebP／BMP 文件，或直接把图片粘贴到当前块。上传沿用已认证的 `/api/upload?purpose=attachment` 接口；附件大小上限为 10 MiB。图片节点将 `![描述](地址)` 作为源文本保存，阅读视图可显示，并可从编辑视图删除。文档保存边界会拒绝非 HTTP(S) 图片网址和不安全的链接协议。

TODO 和完成状态分别使用 `{{[[TODO]]}}` 与 `{{[[DONE]]}}`，点击复选框会切换宏源文本。表格由 `{{[[table]]}}` 所在块和其下的嵌套块组成；表格视图直接读取这些子块，不再为新表格保存单独的投影节点。嵌入节点保存 `{{[[embed]]: ((块ID))}}` 或 `{{[[embed]]: [[页面标题]]}}`，并保留目标文档 ID 用于权限检查和定位。完整宏可以直接输入；解析不到的嵌入保持为可编辑文本。页面引用、块引用和标签沿用原来的结构化表示。

表格左侧的箭头控制下方来源大纲的展开／收起，收起时表格及其单元格仍然显示、可继续编辑，重新展开可查看同一组大纲块。折叠状态复用来源块的 `collapsed` 字段，随文档保存与协作同步；只读快照中也可临时展开查看，不修改快照。箭头支持鼠标点击、Enter 和 Space，提供展开状态与中英文标签。行为参照 2026-10-27 在 Roam `Mega2/page/6mOlNCJZj` 的实际操作；表格箭头保持可见，便于发现。

表格大纲中的空白单元格在下一列子块前保留独立文本行，避免点击空白第一列时光标进入第二列；新建表格、旧文档载入及清空内容后均适用。网格与大纲继续编辑同一组内容，支持纯文本段落；混合格式内容仍在大纲编辑。表格操作栏只在网格拥有焦点时显示，离开网格后移除预留间距。

嵌入表格使用与原表格对齐的箭头和圆点间距。箭头只收起当前嵌入中的来源大纲，网格保持显示；大纲内部的行收起时保留当前行文字，只隐藏子行。嵌入视图的临时折叠不修改源文档，也不影响同一表格的其它嵌入。

图片插入弹窗使用文档页的遮罩、表单、按钮和主题色样式，并在窄屏下保持可用。

插入图片或 embed 后会生成并选中下一行，可直接继续输入。粘贴完整的 Roam 图片语法 `![描述](https://图片地址)` 会插入图片；仅接受不含凭据的 HTTP(S) 地址。打开旧文档时，如果最后一行是图片或 embed 且缺少后续行，编辑器会补出一个空白 Outliner 行，供继续输入。粘贴的 embed 宏仍先显示可编辑文字；按 Enter 或 Tab 转为预览并进入下一行。对于已有图片或 embed，选中预览并按 Enter 也能进入下一行。

实现涉及 `@megaui/content` 的图片节点、`@megaui/ui` 的编辑／阅读组件，以及文档详情页的侧栏与引用计数。块引用来源沿用已有的权限过滤 backlinks 接口，不另行查询每个块。

评论框支持中文输入法组合输入、中英文混输与换行。输入评论触发的页面重渲染不会重新注册正文自动链接转换器，不会恢复正文光标、抢走评论焦点或改变滚动位置；整篇文档、块聚焦及打开侧栏时行为一致。
