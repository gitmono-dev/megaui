# 全站样式基线

以 2026-10-27 的文档详情页为视觉基准，所有路由使用同一套字体层级、画布、边框、控件与面板规则。值的唯一来源为 `packages/ui/src/styles/mega.css`，跨页面应用规则位于 `workspace-surfaces.css`。

## 基准

- 页面标题：默认 30px、800 字重、1.2 行高、-0.02em 字距；随密度设置调整。
- 分区标题：默认 14px、700 字重。
- 操作按钮：默认 12px、7px 圆角、28px 最小高度；主操作为主题强调色，选中项为浅强调色，危险操作保留语义色。
- 表单字段：默认 12.5px、7px 圆角；复选框、单选框、颜色选择及文件选择不套用文本输入框尺寸。
- 面板：文档评论卡片的背景、1px 边框、10px 圆角及 16px × 20px 内边距，不增加常驻阴影。
- 弹出菜单：文档块右键菜单的紧凑字号、4px 圆角、浅选中背景与浮层阴影。
- 工作区页面铺满导航栏右侧的可用宽度，多栏页面的正文占满侧栏之外的空间。标准页面边距随视口调整，桌面 32px，中等屏幕 24px，窄屏 16px。

## 覆盖

首页、Inbox、文档列表／详情／图谱、Issue 列表／详情、CL 列表及各详情标签、Code 根目录／路径、Tag、Agent、Session、频道创建／聊天／私信、全部设置分区，以及中英文入口、登录、注册、找回密码和重置密码。

文档详情页本身消费公共变量，数值保持原样。编辑器工具、正文标题、代码语法高亮、Diff 颜色和图谱几何不应用页面级标题／按钮规则。页面的数据加载、权限、发布与编辑逻辑不变。

窄屏下，工作区导航保留全部入口并使用独立滚动区域；设置导航、表单操作和多栏内容允许换行。深色模式与用户密度设置通过同一组变量生效。键盘焦点、禁用态和选中态保持可辨识。

## 验证

`apps/web/tests/e2e/workspace-surface-style.spec.ts` 在真实 Compose 前端上用独立账号和固定 BFF 数据核对页面样式，比较实际文档标题而不是仅检查 CSS 类名。覆盖亮／暗主题、中英文公共页面、320／768／1024／1440／1920px 的工作区宽度、键盘焦点与密度切换。业务交互由各页面原有 spec 及文档评论中文输入回归补充验证。
