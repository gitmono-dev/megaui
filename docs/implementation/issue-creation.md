# 议题创建

议题创建页使用工作区全宽布局。标题必填，描述支持 Markdown 编辑和预览；可选择负责人、标签、类型、优先级、项目和里程碑。优先级未选择时沿用 P2。

标题旁的进度状态包含待规划、待办、进行中和评审中，默认待规划。进度状态独立于开放和关闭状态，创建时保存并在议题详情中显示。

描述编辑器提供常用 Markdown 格式工具，支持选择、粘贴和拖放附件。附件经登录保护的上传接口存储，上传成功后插入描述；失败时显示错误。创建期间和上传期间禁止重复提交。选择“继续创建”后，创建成功会清空表单并留在创建页。

议题使用 12 位大小写字母和数字组成的固定公开编码，创建时分配，原有议题在迁移时补齐。数字旧地址仍可访问并跳转到公开编码地址。议题描述和评论按 Markdown 渲染，评论支持编辑时预览。

议题正文与评论使用一致的作者卡片、回应与 Markdown 展示；正文编辑权限和自动保存保持不变。描述、评论及其预览中的代码块复用代码浏览和变更视图使用的 diffs 渲染器与主题，根据代码块的语言标记高亮；没有语言标记或无法识别的语言按普通文本显示。
