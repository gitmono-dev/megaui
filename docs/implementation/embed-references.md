# 文档块嵌入的引用次数与删除

文档编辑器将 `mega-embed` 块节点保存到文档正文。右上角的数字表示当前用户**可读取的来源中**指向该目标块的引用出现次数；同一来源文档引用两次计为两次。块引用 `mega-block-ref` 与块嵌入 `mega-embed` 都参与计数。页面嵌入不显示块引用次数。新粘贴但尚未完成自动保存的嵌入会暂时显示至少 `1`，保存成功后刷新目标块的解析数据，显示索引中的次数。

`GET /api/mega/embed/resolve?doc=<文档 ID>&block=<块 ID>` 在成功解析块嵌入时增加 `referenceCount` 数字。计数从 `mega_content_links` 的复合目标 ID（`<文档 ID>:<块 ID>`）读取，并逐条按来源文档的读取权限过滤；无权限的来源不会影响数字或泄露其存在。失败、无权限、循环和页面嵌入响应不承诺此字段。

`0003_embed_block_references.sql` 回填升级前保存的块嵌入。迁移递归读取现有文档正文，比较每个来源与目标的应有引用次数和已建立的索引行数，仅补缺少的行；新保存的文档仍由原有原子索引重建流程维护。部署时应先执行数据库迁移，再切换 Web 应用版本。

编辑器中的嵌入预览可通过悬停出现的“删除嵌入”按钮移除；点选预览后也可按 Backspace 或 Delete。若整个大纲块只含该嵌入，则一并删除该块；若还含文字或子块，则只删除嵌入节点。删除沿用文档自动保存，并在保存成功后刷新引用次数。
